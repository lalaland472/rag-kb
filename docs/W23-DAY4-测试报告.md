# W23 Day 4 — RAG-KB 端到端测试报告

> 日期：2026-08-28 · 测试集：20 条 query · 覆盖 5 类 · 双模式对比（flat / hybrid）
> 系统：本地 BGE 检索 + DeepSeek(deepseek-v4-flash) 生成 + 引用链(页码)

## 一、结果总览

| 指标 | flat | hybrid | 说明 |
|------|:---:|:---:|------|
| ✅ 完全命中+有内容 | 10/20 (50%) | **15/20 (75%)** | 期望论文全部召回且回答有实质内容 |
| △ 部分命中/内容缺失 | 8 | 3 | 命中部分期望论文，或回答无实质内容 |
| ✗ 未命中 | 2 | 2 | 期望论文完全未召回 |
| ⚠ 异常 | 0 | 0 | 无崩溃/报错 |
| 平均耗时 | 8.1s | 8.0s | 本地检索+2次API(生成+HyDE) |

**双模式设计被数据验证**：整体完全命中率从 50% → 75%，hybrid 主题检索显著优于 flat。

## 二、按类别拆解（hybrid 数据）

| 类别 | 说明 | 完全命中率 |
|------|------|:---:|
| A 精确术语 | 英文术语直达 (Transformer/FAISS/FlashAttention...) | 4/4 100% |
| B 中文口语 | HyDE 翻译后检索 | 4/5 80% |
| C 跨篇/主题 | 多论文专题综合 | 2/4 50% |
| D 比较/关系 | 论文间对比 | 3/4 75% |
| E 边界/容错 | 少见表述/宽泛问题 | 2/3 66% |

## 三、双模式各自强项（核心结论）

通过对比，明确验证了 W22 双模式设计的工程价值：

| 场景 | flat | hybrid | 胜出 |
|------|:---:|:---:|------|
| **精确术语召回**（A类）| 4/4 | 4/4 | 平，都强 |
| **中文口语+多主题对齐**（B3 对齐问题）| 50% | **100%** | hybrid |
| **跨篇主题综合**（C2 多智能体）| 50% | **100%** | hybrid |
| **比较类**（D1 RAPTOR/GraphRAG）| 50% | **100%** | hybrid |
| **比较类**（D4 Self-RAG/ReAct）| 50% | **100%** | hybrid |

- **flat（叶子精确召回）**：擅长单术语/明确实体查询，精确、快
- **hybrid（RAPTOR 摘要加权）**：擅长主题意图/跨篇/比较，因为摘要把分散在全文的相关内容**浓缩成主题节点**，query embedding 更容易命中

## 四、残留失败分析（2 个真失败 + 若干部分失败）

**共同根因：检索阶段的多术语 embedding 稀释，非生成问题。**

| ID | 问题 | 根因 | 证据 |
|----|------|------|------|
| C4 | 检索增强高级策略(假设文档+融合) | query 含 2 个术语，BGE 无法同时锚定 | 两模式都命中 GPT3/DPO 等无关 |
| D3 | DPO vs RLHF | 同上，hybrid 反而退化 | flat 命中 DPO(50%)，hybrid 全偏 |
| E1 | 人类记忆模拟 | chunk 切分把"正文论述"和"参考文献列表"混在一段 | 只命中 Generative_Agents 的引用段落 |

**生成模块可靠性证据**：flat 的 B3（对齐/说假话）只召回 InstructGPT（50%命中），但生成端完整答对了 InstructGPT 的人类反馈微调机制 → **检索对了，生成就准，瓶颈 100% 在检索相关性**。

## 五、结论

1. **产品可用**：15/20 完整命中（hybrid），0 异常，平均 8s/问，带页码引用。
2. **双模式设计正确**：主题/比较/口语类必须 hybrid；精确术语类 flat 即可 → 建议 CLI 默认 hybrid。
3. **改进方向**（Day 5 深化）：
   - 多术语 query 可拆分为多个子查询分别检索再融合（query decomposition）
   - E1 类 chunk 质量：切割时可尝试滤除参考文献列表段

## 六、测试集清单（20 条）

A(术语): Transformer自注意力公式 / FAISS十亿级GPU检索 / FlashAttention降内存 / vLLM KV cache
B(口语): LoRA减参 / RAG是什么 / 大模型说假话对齐 / 搜索资料不瞎编 / 树状检索递归摘要
C(跨篇): 高效微调+参数压缩 / 多智能体协作 / LLM裁判评估 / 检索增强高级策略
D(比较): RAPTOR vs GraphRAG / BERT vs Transformer / DPO vs RLHF / Self-RAG vs ReAct
E(边界): 人类记忆模拟 / 思维树24点 / embedding向量化
